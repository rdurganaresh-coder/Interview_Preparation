# SOLID Principles & GoF Design Patterns (`design-patterns`)

Practical Java implementations of Creational, Structural, and Behavioral patterns grounded in SOLID principles.

## Key Features Covered
- SOLID principles applied to Java service architecture
- Creational: Thread-safe Singleton (Bill Pugh / Enum), Builder, and Factory Method
- Structural: Adapter, Decorator, and Dynamic Proxy
- Behavioral: Strategy, Observer, and Template Method
- Replacing complex if-else chains with functional Strategy maps
