# SOLID Design Principles

1. **Single Responsibility Principle (SRP)**: A class should have one clear reason to change.
2. **Open/Closed Principle (OCP)**: Open for extension (via interfaces/polymorphism), closed for modification.
3. **Liskov Substitution Principle (LSP)**: Subtypes must be substitutable for their base types without breaking expected behavior.
4. **Interface Segregation Principle (ISP)**: Prefer focused, client-specific interfaces over bloated "god" interfaces.
5. **Dependency Inversion Principle (DIP)**: High-level modules should depend on abstractions (`interface`), not concrete implementations.
