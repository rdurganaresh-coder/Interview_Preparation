# Java Basics & Modern Java 17 (`java-basics`)

Core object-oriented fundamentals, records, sealed hierarchies, immutability, and custom exception design.

## Key Features Covered
- Java 17 Records for concise immutable data carriers
- Sealed interfaces and permitted classes for domain modeling
- OOP pillars: Encapsulation, Inheritance, Polymorphism, and Abstraction
- Immutable class design rules (final class, defensive copying)
- Checked vs Unchecked custom exception hierarchy
- Text blocks and switch expressions
